# TechVibe E-Commerce & Chatbot Support

Bem-vindo à documentação do **TechVibe E-Commerce**, uma aplicação completa de E-Commerce integrada com um Chatbot Inteligente focado em atendimento ao cliente (suporte a pedidos, devoluções, reembolsos e dúvidas gerais).

## O que é este projeto?
O sistema é uma solução híbrida que engloba um frontend estático para navegação e compras (e-commerce) e um backend poderoso baseado em FastAPI. O backend não só serve as requisições web como também abriga um pipeline de Processamento de Linguagem Natural (NLP) usando spaCy, Scikit-learn e TF-IDF para o chatbot responder e resolver intenções dos clientes.
